# Bank Fraud Detection using Machine Learning

## Project Overview
This project is developed as part of the Glowlogics AI in Python Internship.

The project uses Machine Learning to detect potentially fraudulent bank transactions.

## Objective
To build a machine learning model that can classify bank transactions as legitimate or fraudulent.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook / Google Colab

## Dataset
A synthetic transaction dataset was created for educational demonstration purposes.

The dataset contains transaction-related features such as:
- Transaction amount
- Transaction hour
- Merchant risk
- Device risk
- IP risk
- Distance
- Transaction velocity
- Failed attempts
- International transaction
- New device

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Results
The Random Forest model achieved:

- Accuracy: 95.42%
- Precision: 34.15%
- Recall: 33.33%
- F1 Score: 33.73%
- ROC-AUC: 85.67%

These results are based on synthetic data and are for educational demonstration only.
